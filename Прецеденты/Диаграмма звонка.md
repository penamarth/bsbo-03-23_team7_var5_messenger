# Описание прецедента: Звонок (аудио/видео)

## Рамки  
Подсистема аудио- и видео-звонков мессенджера.

## Уровень  
Задача, определённая пользователем.

## Основной исполнитель  
Пользователь, совершающий звонок.

## Заинтересованные лица и их требования

**Звонящий пользователь:**  
- хочет быстро инициировать звонок;  
- хочет видеть статус звонка;  
- хочет завершить звонок в любой момент.

**Получатель:**  
- хочет увидеть уведомление о входящем звонке;  
- хочет иметь возможность принять или отклонить вызов.

**Система мессенджера:**  
- должна корректно устанавливать медиасессию;  
- должна уведомлять участников о статусе вызова;  
- должна завершать звонок корректно.

**Сервис звонков:**  
- отвечает за установление медиа-соединения;  
- должен обновлять статус звонка в базе данных.

## Предусловия
1. Оба пользователя зарегистрированы и авторизованы.  
2. Оба устройства имеют доступ к сети.  
3. Пользователь А имеет право позвонить пользователю Б.

## Постусловия
1. Звонок установлен, отклонён или завершён — статус записан в БД.  
2. Участники получили соответствующие уведомления.  
3. Медиасессия корректно завершена.

---

## Основной успешный сценарий

1. Пользователь выбирает контакт и нажимает «Позвонить».  
2. Клиентское приложение отправляет запрос серверу.  
3. Сервер создаёт сессию звонка через сервис звонков.  
4. Сессия сохраняется в базе данных.  
5. Получателю отправляется push-уведомление о входящем вызове.  
6. Получатель принимает вызов.  
7. Система устанавливает медиасессию между участниками.  
8. Оба участника находятся в режиме разговора.  
9. По завершении звонка сервер фиксирует статус «завершён».

---

## Альтернативные сценарии

### Получатель отклоняет звонок
- Система обновляет статус звонка → «отклонён».  
- Звонящий получает уведомление «Пользователь отклонил вызов».

### Получатель недоступен
- Система возвращает ошибку «Пользователь недоступен».  
- Звонящий получает соответствующее уведомление.

### Ошибка медиасессии
- Соединение не удалось установить.  
- Оба участника получают уведомление об ошибке.

---

## Частота использования
Средняя — используется регулярно, но реже, чем обмен сообщениями.

---

## Открытые вопросы
1. Нужно ли сохранять длительность каждого звонка?  
2. Должны ли звонки приходить сразу на все устройства пользователя?  
3. Нужен ли отдельный сервис для видеозвонков?

```plantuml
@startuml
actor "Пользователь" as User
actor "Получатель" as Callee
participant "Клиентское приложение" as App
participant "Клиентское приложение получателя" as CalleeApp
participant "Сервер мессенджера" as Server
participant "Сервис звонков" as CallService
participant "База данных" as DB
participant "Сервис уведомлений" as NotificationService

== Исходящий звонок ==

User -> App: Нажать "Позвонить"
activate App
App -> Server: startCall(callerId, calleeId, callType)
activate Server

Server -> CallService: createCallSession(callerId, calleeId, callType)
activate CallService

CallService -> DB: saveCallSession(callerId, calleeId, callType)
activate DB
DB --> CallService: callId, статус "звонок инициирован"
deactivate DB

CallService -> DB: checkCalleeAvailability(calleeId)
activate DB
DB --> CallService: Статус/настройки получателя
deactivate DB

alt Получатель недоступен (офлайн/заблокирован/не принимает звонки)
    CallService --> Server: Ошибка установки звонка
    Server --> App: callFailed(reason)
    App --> User: Показать ошибку звонка
    deactivate CallService
    deactivate Server
    deactivate App
else Получатель доступен
    CallService --> Server: callSessionCreated(callId)
    Server --> App: ringing(callId)
    App --> User: Показать экран "Вызов..."
    
    CallService -> NotificationService: notifyIncomingCall(calleeId, callId, callerInfo, callType)
    activate NotificationService
    NotificationService -> CalleeApp: pushIncomingCall(callId, callerInfo, callType)
    deactivate NotificationService
    
    deactivate CallService
    deactivate Server
    deactivate App
end

== Ответ на звонок ==

Callee -> CalleeApp: Принять / Отклонить вызов
activate CalleeApp

alt Принять вызов
    CalleeApp -> Server: acceptCall(callId)
    activate Server
    Server -> CallService: connectParticipants(callId)
    activate CallService
    
    CallService -> CallService: Установить медиасессию
    CallService --> Server: callConnected(callId)
    deactivate CallService
    
    Server --> App: callConnected(callId)
    App --> User: Показать экран разговора
    
    Server --> CalleeApp: callConnected(callId)
    CalleeApp --> Callee: Показать экран разговора
    deactivate Server
else Отклонить вызов
    CalleeApp -> Server: rejectCall(callId, reason)
    activate Server
    Server -> CallService: cancelCall(callId, reason)
    activate CallService
    
    CallService -> DB: updateCallStatus(callId, "отклонен")
    activate DB
    DB --> CallService: Статус обновлен
    deactivate DB
    
    CallService --> Server: callRejected(callId, reason)
    deactivate CallService
    
    Server --> App: callRejected(callId, reason)
    App --> User: Показать "Звонок отклонён"
    deactivate Server
end

deactivate CalleeApp

== Завершение звонка ==

User -> App: Нажать "Завершить"
activate App
App -> Server: endCall(callId)
activate Server

Server -> CallService: terminateCall(callId)
activate CallService

CallService -> DB: updateCallStatus(callId, "завершен")
activate DB
DB --> CallService: Статус обновлен
deactivate DB

CallService --> Server: callEnded(callId)
deactivate CallService

Server --> App: callEnded(callId)
App --> User: Закрыть экран разговора

Server --> CalleeApp: callEnded(callId)
CalleeApp --> Callee: Показать "Звонок завершён"

deactivate Server
deactivate App

@enduml
```
